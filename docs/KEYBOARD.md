# Keyboard Shortcuts

Press `?` on any page for an overlay with that page's shortcuts (`Esc` or `?` closes it). When a button or link has keyboard focus, `Enter` and `Space` act on that control, not on the page, and the first `Esc` only hands focus back; `Esc` leaves a page only from rest.

## Commander
| Key | Action |
|---|---|
| `/` | Focus search |
| `↑ ↓ PgUp PgDn Home End` | Move through rows (with `Shift` to extend selection) |
| `Enter` | Tick / untick the current row |
| `Space` | Preview the current video |
| `←` / `Shift+Tab` | Move into the rail (library, audits, playlists, tags); `→` returns |
| double-click a tag | Rename it (or edit the name in the tag sheet and Save) |
| `T` | Start triage (with 2+ ticked: batch triage) |
| `W` / `H` | Open Watch / History |
| `Esc` | Close preview, or clear filters |
| `Z` | Undo, while an undo toast is showing (Watch: note delete, Drop) |
| In preview: `K` `J` `L` `M` | Play-pause, back 10 s, forward 10 s, mute |

## Preview "player mode"
`F` or `Esc` toggles. `Space`/`K` play, `←/→` ±5 s, `↑/↓` volume, `<` `>` speed, `Home`/`End` start/end, `Enter` fullscreen, `Tab` hand focus to the video.

## Triage
| Key | Action |
|---|---|
| `Enter` | Confirm the tags and go to the next video |
| `→` or `S` | Skip |
| `←` | Back one video (reopens it if you had dropped it) |
| `X` | Drop |
| `T` / `N` | Focus tag / note box |
| `V` or `Space` | Start/stop voice note (`V` only in batch triage, where `Space` previews) |
| `F` | Player mode (same keys as above) |
| `J` `K` `L` | Back 10 s / play-pause / forward 10 s |

### Batch triage
With nothing highlighted: `Enter` confirms all (asks first when there are two or more), `X` drops all. `↑/↓` highlight a video · `Space` preview · `R` remove from batch · `Enter` fold/unfold · `Esc` or `←` back to the controls · `F` focus the player.

## Watch
| Key | Action |
|---|---|
| `Space` / `K` | Play / pause |
| `← →` / `J L` | Seek 5 s / 10 s |
| `↑ ↓` | Volume |
| `M` | Mute |
| `0`–`9` | Jump to 0–90 % |
| `Home` `End` | Start / end |
| `< >` | Slower / faster |
| `[` `]` `\` | Set A, set B, clear loop |
| `B` | Note at current time (`Shift`: on highlighted line) |
| `V` | Voice note (`Shift`: on highlighted line) |
| `T` / `N` | Focus tag / note box |
| `PgDn` / `PgUp` | Next / previous in queue |
| `Q` | Focus the queue |
| `Y` | Captions / transcript |
| `G` | Open on YouTube |
| `C` | Copy a link to this moment |
| `F` / `Enter` | Fullscreen |
| `H` | History |
| `Esc` | Leave the page |

### Queue focus (`Q`)
`↑/↓` move highlight · `Alt+↑/↓` reorder · `Home/End` · `Space`/`Enter` play · `Esc`, `←` or `Q` leave.

## History
`/` search · `↑/↓` move · `Enter` open · `Esc` leave field.

## Import
| Key | Action |
|---|---|
| `Enter` | Run the import once files are staged; open Commander once it is done |
| `Esc` | Back a step; from the drop zone, back to Commander |
