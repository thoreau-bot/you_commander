# Keyboard Shortcuts

Press `?` on any page for an overlay with that page's shortcuts (`Esc` or `?` closes it). When a button or link has keyboard focus, `Enter` and `Space` act on that control, not on the page, and the first `Esc` only hands focus back; `Esc` leaves a page only from rest.

## Commander
| Key | Action |
|---|---|
| `/` | Focus search |
| `↑ ↓ PgUp PgDn Home End` | Move through rows (with `Shift` to extend selection) |
| `Enter` | Tick / untick the current row |
| click a row's empty space | Tick / untick that row (a double-click counts once; the title still opens the video) |
| `Space` | Preview the current video |
| `←` / `Shift+Tab` | Move into the rail (library, audits, playlists, tags); `→` returns |
| double-click a tag | Rename it (or edit the name in the tag sheet and Save) |
| `T` | Start Triage (with 2+ ticked: batch triage) |
| `W` | Watch in Theater: the open (or highlighted) video on the Watch page, carrying on from where it is; with 2+ ticked, those in list order. Also in the rail. From an open preview the preview pauses; the Watch page picks up at the same moment in the same play state, and `Esc` there brings you back with the same video open, at the Watch page's time and play state. `E` does the same with Triage. |
| `H` | History |
| `Esc` | Close preview, or clear filters |
| `Z` | Undo, while an undo toast is showing (Watch: note delete, Drop) |
| In preview: `K` `J` `L` `M` `Y` `E` | Play-pause, back 10 s, forward 10 s, mute, open on YouTube, triage this video (from this moment; `Esc` in Triage comes back) |

## Video controls (`F`)
On a Commander preview and in Triage, `F` turns video controls on; `Esc` is the only way to turn them off (in fullscreen, the first `Esc` leaves fullscreen). While they are on: `Space`/`K` play-pause, `←/→` ±5 s, `J/L` ±10 s, `↑/↓` volume, `M` mute, `0`–`9` jump, `<` `>` speed, `Home`/`End` start/end, `F` or `Enter` fullscreen, `W` Watch in Theater from the same moment, `Tab` hands the keyboard to YouTube's own controls (`Tab`/`Shift+Tab` past them comes back).

The label under the video reads `Tab Exit YouTube Video Controls` while they are on. A card at the bottom right ("Video Controls ON") lists these keys. Other messages may cover it for a while (never more than 10–15 s, depending on their length); then it comes back. Clicking the video while controls are on keeps the app's keys working.

## Triage
| Key | Action |
|---|---|
| `Enter` | Confirm the tags and go to the next video |
| `→` or `S` | Skip |
| `←` | Back one video (reopens it if you had dropped it) |
| `X` | Drop |
| `T` / `N` | Focus tag / note box |
| `V` or `Space` | Start/stop voice note (`V` only in batch triage, where `Space` previews) |
| `F` | Video controls (same keys as above, including `W`) |
| `W` | Watch in Theater: this video, from the current moment; `Esc` there comes back to it |
| `M` / `G` | Sound on/off / open on YouTube |
| right-click | The same actions as a menu |
| `J` `K` `L` | Back 10 s / play-pause / forward 10 s |

### Batch triage
With nothing highlighted: `Enter` confirms all (asks first when there are two or more), `X` drops all. `↑/↓` highlight a video · `Space` preview · `R` remove from batch · `Enter` fold/unfold · `Esc` or `←` back to the controls · `F` video controls for the previewed video · `W` Watch in Theater, with the batch as the queue.

## Watch
| Key | Action |
|---|---|
| `Space` / `K` | Play / pause |
| `← →` / `J L` | Seek 5 s / 10 s |
| `↑ ↓` | Volume |
| `M` | Mute |
| `0`–`9` | Jump to 0–90 % |
| `Home` `End` | Start / end |
| `< >` | Slower / faster |
| `[` `]` `\` | Set A, set B, clear loop |
| `B` | Note at current time (`Shift`: on highlighted line) |
| `V` | Voice note (`Shift`: on highlighted line) |
| `T` / `N` | Focus tag / note box |
| `PgDn` / `PgUp` | Next / previous in queue |
| `Q` | Focus the queue |
| `Y` | Captions / transcript |
| `G` | Open on YouTube |
| `C` | Copy a link to this moment |
| `F` / `Enter` | Fullscreen |
| `H` | History |
| `Esc` | Leave the page (back to where you came from) |

The video always has the keyboard on this page: the stage carries the same ring as video controls elsewhere, and a "Video Controls ON" card at the bottom right lists the keys. Owner & Visibility (Commander rail) sorts by any column; click a header, again to reverse.

### Queue focus (`Q`)
`↑/↓` move highlight · `Alt+↑/↓` reorder · `Home/End` · `Space`/`Enter` play · `Esc`, `←` or `Q` leave.

## History
| Key | Action |
|---|---|
| `/` | Filter |
| `↑ ↓ Home End` | Move the highlight |
| `Enter` or `W` | Watch in Theater: the highlighted video, with the rest of the list (in this order) as its queue |
| `T` | Triage the highlighted video |
| `Esc` | Leave the filter box; from rest, back to Commander |

## Import
| Key | Action |
|---|---|
| `Enter` | Run the import once files are staged; open Commander once it is done |
| `Esc` | Back a step; from the drop zone, back to Commander |
