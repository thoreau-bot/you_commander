Drag in the Takeout .zip, the playlists folder, or any playlist .csv files.

Everything stays on this computer. Only the playlist files are read — watch history, comments and everything else in a Takeout are never opened.

How do I get my Takeout?
  1. Go to takeout.google.com and click Deselect all.
  2. Tick YouTube and YouTube Music, then All YouTube data included, and keep only playlists.
  3. Create the export, download the .zip, and drop it here.
  4. Have more than one account? Import each one separately and give each its own name.
